## 快速开始

### 环境要求

- Windows 10/11
- Node.js 18+
- Python 3.11+（服务端）
- Docker（可选，用于数据库）

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/LSPO2/EZTODO.git
cd EZTODO

# 2. 安装前端依赖
cd apps/desktop
npm install

# 3. 启动开发服务器
npm run dev
```

## 启动应用

### 方式一：开发模式

```bash
# 启动后端（需要先启动 PostgreSQL）
cd services/api
source venv/Scripts/activate  # Windows: venv\Scripts\activate
uvicorn main:app --reload

# 启动前端
cd apps/desktop
npm run dev
```

### 方式二：使用 Docker

```bash
# 启动数据库和 API
cd infra/docker
docker-compose up -d

# 启动前端
cd apps/desktop
npm run dev
```

### 方式三：生产构建

```bash
# 构建安装包
cd apps/desktop
npm run tauri build

# 安装包位置
# apps/desktop/src-tauri/target/release/bundle/nsis/
```

## 基本功能

### 1. 创建任务

**普通创建：**
1. 在顶部输入框输入任务标题
2. 点击"添加"按钮或按 Enter

**AI 创建：**
1. 点击输入框左侧的 🤖 按钮切换到 AI 模式
2. 输入自然语言，如"明天下午三点开会"
3. 点击"AI 创建"按钮
4. 确认或修改解析结果

### 2. 编辑任务

1. 点击任务卡片打开详情面板
2. 修改标题、备注、日期、优先级等
3. 修改自动保存

### 3. 完成任务

- 点击任务左侧的圆形复选框
- 已完成任务会显示删除线

### 4. 删除任务

1. 点击任务卡片
2. 点击详情面板底部的"删除任务"
3. 任务进入回收站（30天后自动清除）

### 5. 创建子任务

1. 打开父任务详情
2. 在"子任务"区域输入子任务标题
3. 点击"+"按钮添加

## AI 智能创建

### 支持的输入格式

| 输入示例 | AI 解析结果 |
|---|---|
| 明天下午三点交报告 | 标题：交报告，时间：明天15:00 |
| 下周五前交报告，提前一天提醒 | 标题：交报告，截止：下周五，提醒：下周四 |
| 每周一三五晚上八点跑步 | 标题：跑步，重复：每周一三五，时间：20:00 |
| 做实验报告，分成收集数据、画图、写分析 | 父任务 + 3个子任务 |
| 月底之前完成 | 截止：本月最后一天 |

### 置信度说明

| 置信度 | 行为 |
|---|---|
| 高 | 自动创建任务，显示撤销按钮 |
| 中 | 显示确认卡片，用户可修改 |
| 低 | 必须手动确认后才创建 |

### 安全特性

- 防止提示注入攻击
- 不执行用户输入中的指令
- AI 超时时可手动创建任务

## 提醒设置

### 添加提醒

1. 打开任务详情
2. 在"提醒"区域选择时间
3. 点击"+ 添加提醒"

### 提醒类型

- **准时提醒**：在指定时间提醒
- **提前提醒**：提前 N 分钟/小时/天提醒
- **稍后提醒**：收到提醒后选择 10分钟/1小时/明天

### 安静时段

- 默认 22:00 - 08:00
- 普通提醒会延后到安静时段结束
- 重要任务可设置绕过安静时段

## 数据管理

### 导入数据

支持格式：
- **CSV**：通用表格格式
- **JSON**：完整数据备份
- **Markdown**：复选框格式

导入步骤：
1. 点击侧边栏"数据管理"
2. 选择"导入"标签
3. 选择文件
4. 预览并确认
5. 点击"导入"

### 导出数据

支持格式：
- **JSON**：完整数据，可导入恢复
- **CSV**：可用 Excel 打开
- **Markdown**：复选框格式，便于阅读

导出步骤：
1. 点击侧边栏"数据管理"
2. 选择"导出"标签
3. 选择格式和选项
4. 点击"导出数据"

### 备份恢复

**创建备份：**
1. 点击侧边栏"数据管理"
2. 选择"备份恢复"标签
3. 点击"创建备份"
4. 选择保存位置

**恢复备份：**
1. 点击"选择备份文件"
2. 预览备份信息
3. 确认恢复

## 常见问题

### Q: AI 功能不工作？

A: 检查以下配置：
1. 确保 `AI_API_KEY` 已配置
2. 确保 DeepSeek API 可访问
3. 检查网络连接

### Q: 提醒不显示？

A: 检查以下设置：
1. 确保应用在托盘运行
2. 检查系统通知权限
3. 确认不在安静时段

### Q: 数据丢失了？

A: 尝试以下恢复：
1. 检查回收站
2. 使用导入功能恢复备份
3. 从服务器重新同步

### Q: 同步失败？

A: 检查以下配置：
1. 确保服务器地址正确
2. 确保网络连接正常
3. 检查登录状态
