## 验收场景列表

### ACC-DATA-001 删除任务进入回收站

**场景**：删除一个任务

**预期结果**：
- 任务从列表消失
- 任务出现在回收站
- 显示删除时间和剩余天数

**验证步骤**：
1. 创建一个任务
2. 删除该任务
3. 确认任务从列表消失
4. 进入回收站
5. 确认任务在回收站中

---

### ACC-DATA-002 恢复删除的任务

**场景**：从回收站恢复任务

**预期结果**：
- 任务回到原位置
- 任务数据完整

**验证步骤**：
1. 删除一个任务
2. 进入回收站
3. 点击恢复
4. 确认任务回到原位置
5. 确认任务数据完整

---

### ACC-DATA-003 删除父任务级联删除

**场景**：删除一个有子任务的父任务

**预期结果**：
- 父任务进入回收站
- 子任务一起进入回收站
- 恢复时一起恢复

**验证步骤**：
1. 创建父任务和子任务
2. 删除父任务
3. 进入回收站
4. 确认父任务和子任务都在
5. 恢复父任务
6. 确认子任务一起恢复

---

### ACC-DATA-004 永久删除确认

**场景**：永久删除任务

**预期结果**：
- 显示确认对话框
- 确认后永久删除
- 不可恢复

**验证步骤**：
1. 进入回收站
2. 点击永久删除
3. 确认显示确认对话框
4. 确认删除
5. 确认任务消失
6. 确认无法恢复

## 验收标准

M5 阶段验收通过的条件：

1. ✅ 所有删除进入回收站
2. ✅ 可以恢复删除的任务
3. ✅ 恢复父任务时子任务一起恢复
4. ✅ 30 天后自动清理
5. ✅ 可以导入 CSV 和 JSON
6. ✅ 导入前可以预览
7. ✅ 导入可以撤销
8. ✅ 可以导出 JSON 和 CSV
9. ✅ 可以手动备份和恢复
10. ✅ 备份恢复校验完整性
