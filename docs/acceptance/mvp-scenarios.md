## 验收场景列表

### ACC-001 AI 创建任务（带提醒）

**输入**：
```
明天下午三点交实验报告，提前一天和一小时提醒
```

**预期结果**：
| 项目 | 预期值 |
|---|---|
| 任务标题 | 交实验报告 |
| 计划时间 | 明天 15:00 |
| 提醒 1 | 明天 15:00（准时提醒） |
| 提醒 2 | 明天 14:00（提前 1 小时） |
| 提醒 3 | 今天 15:00（提前 1 天） |
| 置信度 | 高 |

**验证步骤**：
1. 在快速添加栏输入上述文字
2. 点击"AI 创建"按钮
3. 确认任务自动创建
4. 检查任务详情中的时间和提醒设置

---

### ACC-002 AI 创建重复任务

**输入**：
```
每周一晚上八点复习高数
```

**预期结果**：
| 项目 | 预期值 |
|---|---|
| 任务标题 | 复习高数 |
| 计划时间 | 周一 20:00 |
| 重复规则 | 每周，周一 |
| 置信度 | 高 |

**验证步骤**：
1. 输入上述文字
2. 点击"AI 创建"
3. 确认任务自动创建
4. 检查重复规则设置
5. 完成任务后确认生成下一次实例

### ACC-003 AI 创建父子任务

**输入**：
```
月底完成实习报告，分为整理照片、写正文、调整格式
```

**预期结果**：
| 项目 | 预期值 |
|---|---|
| 父任务标题 | 完成实习报告 |
| 子任务 1 | 整理照片 |
| 子任务 2 | 写正文 |
| 子任务 3 | 调整格式 |
| 截止时间 | 本月最后一天 |
| 置信度 | 高 |

**验证步骤**：
1. 输入上述文字
2. 点击"AI 创建"
3. 确认父任务和 3 个子任务创建成功
4. 检查父子关系正确
5. 验证完成进度显示（0/3）

---

### ACC-004 离线创建任务

**场景**：断网状态下创建任务

**预期结果**：
- 任务创建成功并保存到本地 SQLite
- 同步状态显示"离线"
- 重启软件后任务仍存在

**验证步骤**：
1. 断开网络连接
2. 创建一个普通任务
3. 确认任务显示在列表中
4. 关闭软件
5. 重新打开软件
6. 确认任务仍然存在

---

### ACC-005 离线同步

**场景**：恢复网络后自动同步

**预期结果**：
- 离线创建的任务自动上传到服务器
- 同步状态变为"已同步"
- 其他设备可以看到同步的任务

**验证步骤**：
1. 在离线状态下创建任务
2. 恢复网络连接
3. 等待自动同步（或手动点击同步）
4. 确认同步状态变为"已同步"
5. 在另一台设备登录，确认任务可见

---

### ACC-006 托盘提醒

**场景**：主窗口关闭到托盘后仍能提醒

**预期结果**：
- 主窗口关闭后程序在托盘运行
- 到达提醒时间时弹出系统通知
- 点击通知可打开主窗口并定位到任务

**验证步骤**：
1. 创建一个 1 分钟后的提醒任务
2. 关闭主窗口（点击 X 按钮）
3. 确认程序在托盘运行
4. 等待提醒时间到达
5. 确认系统通知弹出
6. 点击通知，确认主窗口打开

---

### ACC-007 回收站恢复

**场景**：删除包含子任务的项目后恢复

**预期结果**：
- 父任务和子任务一起进入回收站
- 恢复父任务时子任务一起恢复
- 恢复后父子关系保持正确

**验证步骤**：
1. 创建一个父任务和 2 个子任务
2. 删除父任务
3. 进入回收站
4. 确认父任务和子任务都在回收站
5. 点击"恢复"
6. 确认父任务和子任务都恢复
7. 确认父子关系正确

### 中文测试语料

```
1. 明天下午三点交报告

8. 过两天提醒我续费
9. 月底之前完成
10. 同一段文字包含三个独立任务
11. 包含否定表达，例如"不要提醒我"
12. 包含过去日期、日期冲突和无效时间
```
