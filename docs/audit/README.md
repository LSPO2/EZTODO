## 状态口径

- **已实现**：代码存在，但不代表已经过真实运行验收。
- **已接线**：界面、Store/Service、Repository 或原生端调用链已连通。
- **自动化已验证**：相关类型检查、单元测试、构建或静态门禁通过。
- **真机待验证**：需要 Windows/Tauri、真实 API、睡眠/托盘、安装包或多设备环境。
- **已验收**：自动化与所需真机证据均通过，且有可复查记录。
