## 回滚计划

### 服务器回滚

```bash
# 停止服务
docker-compose down

# 恢复旧版本镜像
docker-compose up -d api:old-version

# 恢复数据库（如需要）
./infra/scripts/restore-db.sh ./backups/pre-upgrade-backup.sql.gz
```

### 客户端回滚

1. 卸载新版本
2. 安装旧版本
3. 数据自动保留
