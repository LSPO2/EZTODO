📄 产品规则文档

  • 单用户模式，服务端暂不开放注册
  • 登录方式：服务器地址 + 用户名 + 密码
  • 任务层级最多 3 级
  • 时区跟随 Windows 系统
  • 日期、截止时间和提醒时间分离
  • 回收站保留 30 天
  • AI 高置信度自动创建

👨‍👩‍👧‍👦 父子任务规则

  • 子任务全部完成时自动完成父任务
  • 完成父任务需确认（仅父/同时完成所有）
  • 重新打开父任务需确认
  • 禁止循环引用
  • 级联删除和恢复

🎨 UI 原型设计

  • 登录与服务器配置页
  • 主界面：侧边栏 + 任务列表 + 详情面板
  • Inbox、今天、未来7天、已逾期、已完成、回收站
  • AI 解析确认卡片
  • 重复规则编辑器
  • 同步状态和冲突提示

🏗️ 工程基础

  • Monorepo 结构（apps/services/packages/infra）
  • Tauri 2 + React + TypeScript + Vite
  • FastAPI + SQLAlchemy + PostgreSQL
  • Docker Compose 配置
  • 共享协议包（Task、Reminder、Sync、AI）

💾 本地数据库

  • SQLite 数据库初始化（WAL 模式）
  • 版本化迁移机制（4个版本）
  • 核心数据表（tasks、projects、tags 等）
  • 查询索引优化
  • 外键约束和数据完整性

✅ 任务 CRUD

  • 创建任务（标题、优先级、日期）
  • 编辑任务详情
  • 完成/取消完成任务
  • 软删除任务
  • 搜索任务
  • Repository 层封装

👁️ 视图和搜索

  • 收件箱、今天、未来7天、已逾期、已完成、回收站
  • 按优先级筛选（P1-P4）
  • 按状态筛选（待办/已完成/已取消）
  • 父子任务显示和进度
  • 排序功能

🖥️ 客户端外壳

  • 窗口状态保存/恢复
  • 系统托盘（快速添加、今天、同步、设置、退出）
  • 快捷键（Ctrl+N、Ctrl+K、Ctrl+Enter、Escape）
  • 批量操作（多选、完成、删除、撤销）
  • DPI 缩放支持
